## Cómo estudiar este curso

1. Lee la [visión general](./00-vision-general.md).
2. Practica en paralelo: **una VM de Linux** y tu Windows diario.
3. Módulos 1 → 6; la línea de comandos se domina usándola.
4. El módulo 6 integra todo en escenarios reales.
