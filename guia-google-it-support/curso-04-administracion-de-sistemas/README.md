## Cómo estudiar este curso

1. Lee la [visión general](./00-vision-general.md).
2. Módulos 1 → 5 en orden; usa tu VM Linux como "servidor" de práctica.
3. Módulo 6: casos reales integradores (tipo entrevista de trabajo).
4. Consejo profesional: este curso es el que abre puertas laborales (sysadmin junior).
