## Cómo estudiar este curso

1. Lee la [visión general](./00-vision-general.md).
2. Módulos 1 → 6 en orden; este curso combina conceptos con práctica (TryHackMe).
3. Aplica lo aprendido a TU equipo: hardening + 2FA + backups — lo que le recomendaste al cliente, hazlo contigo.
4. El módulo 6 integra la respuesta a incidentes completa (lo que ya practicamos en el proyecto Soluciona con el incidente real de malware).
