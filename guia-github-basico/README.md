## Método de estudio

1. Lee el módulo → 2. mira su diagrama → 3. haz el ejercicio en tu repositorio (es la práctica real: este mismo proyecto) → 4. explica en voz alta lo que hiciste → 5. completa el checklist → 6. repasa en días 2-3, 7 y 30.

Rúbrica de dominio: **Novato → Aprendiz → Competente → Experto**. Tu meta: nivel 3 (navegar sin ayuda) antes del módulo 6, y nivel 4 (enseñarlo a otro) al terminar el proyecto final.
