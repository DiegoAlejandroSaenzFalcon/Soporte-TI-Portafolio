## 1. Descargar todo: el botón verde Code

1. En la **pestaña Code**, haz clic en el botón verde **"Code"** (arriba a la derecha).
2. En el menú, elige **"Download ZIP"**.
3. Descomprime el archivo en tu PC (clic derecho → "Extraer todo").

El resultado: **una copia completa y exacta** del repositorio en tu disco: todos los cursos, todos los módulos, todos los diagramas. Momento clave: ojo con la ubicación — crea una carpeta limpia, ej. `C:\MisApuntes\Soporte-TI`.

## 2. ¿Qué es y qué NO es la copia local?

| La copia ZIP... | Sincronización (la que veremos más adelante) |
|-----------------|----------------------------------------------|
| Es un **instante congelado** del día que la descargaste | Se actualiza sola (se "empuja" y se "baja") |
| Sirve para estudiar sin internet | Sirve para trabajar desde varios equipos |
| Si GitHub cambia, tu copia NO cambia | Los cambios viajan en ambos sentidos |
| Perfecta para leer y consultar | Perfecta para editar y colaborar |

**Regla de memoria**: el ZIP es como **fotocopiar un libro**; la sincronización es como tener **el libro original conectado**. Para estudiar, la fotocopia basta; para editar el proyecto, necesitamos el original (módulo 6).

## 3. Organiza tu biblioteca local (hábito profesional)

Estructura sugerida para tus apuntes:

```
C:\MisApuntes\
├── Soporte-TI\            ← la copia descomprimida (siempre al día)
├── Proyectos-propios\     ← tus experimentos (CV, diagramas, ejercicios)
└── LECTURA-000.txt         ← un archivo de "leído hasta" para no perderte
```

**Consejo de estudio**: después de leer un módulo, marca tu avance en el archivo `LECTURA` con fecha y próximas repeticiones (días 2-3, 7 y 30 — repetición espaciada). Así tu copia local se convierte en tu **cuaderno de bitácora**.

## 4. Editar tus documentos localmente (sin miedo)

Los archivos `.md` son texto plano: puedes abrirlos con el Bloc de notas, Word (guardando como texto) o un editor gratuito (VS Code, Notepad++). Los `.svg` son imágenes vectoriales editables con cualquier editor de SVG.

**Regla antes de editar tu copia**: siempre guarda una copia de seguridad (regla 3-2-1 de los documentos):

- **3 copias**: GitHub (nube) + tu carpeta + un USB/nube de repuesto
- **2 medios**: PC + USB o PC + nube
- **1 fuera de sitio**: la nube o la casa de un familiar

Tus apuntes valen horas de trabajo: merecen la misma estrategia que los backups de las guías.

## 5. Ejercicio guiado

1. Descarga el ZIP y descomprímelo en `C:\MisApuntes\Soporte-TI`.
2. Verifica: abre `README.md` con el editor de texto y confirma que el texto coincide con GitHub.
3. Crea tu archivo `LECTURA-000.txt` con la fecha de hoy y "módulo GH-04 leído".
4. Abre un SVG local y un MODULO local: compáralos con la versión web (¿qué notas?).
5. Auto-explicación: "¿qué diferencia hay entre ZIP y sincronización?" (1 minuto en voz alta).
