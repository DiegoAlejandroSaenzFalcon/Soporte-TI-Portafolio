## 1. El proyecto: tu repositorio de presentación

Vas a crear **"mi-portafolio-ti"**: con tu CV en Markdown, una carpeta de proyectos y un README. Todo desde el navegador — sin terminal. Empieza:

1. Con sesión iniciada, botón **"+"** (arriba a la derecha) → **"New repository"**.
2. Nombre: `mi-portafolio-ti`. Descripción: una frase. Visibilidad: **pública**.
3. Marca "Add a README file" (así nace con portada).
4. Clic en **"Create repository"** — ¡ya tienes tu primer repositorio!

## 2. Subir archivos (arrastrar y soltar)

Haz clic en **"Add file"** → **"Upload files"** → arrastra archivos desde tu PC (tu CV en `.md` por ejemplo) → **"Commit changes"** con un mensaje profesional ([verbo + qué]).

**Camino alternativo**: "Add file" → "Create new file" → empieza a escribir `proyectos/practica-redes.md` (GitHub crea la carpeta solita con tu ruta).

## 3. Editar desde la web (la primera edición)

1. Abre `README.md` → clic en el **lápiz** (editar).
2. Cambia el título y añade una línea tuya.
3. Abajo: mensaje de commit ("Actualiza la portada con mi presentación") y botón **"Commit changes"**.
4. Ve a la pestaña **Commits**: verás tu historial personal empezando.

**Momento de orgullo**: acabas de hacer lo mismo que se hace con este repositorio: editar + commit. Ya no solo lees GitHub: lo usas.

## 4. Concepto estrella: las ramas (branch) — solo entiéndelo

Una **rama** es una copia de trabajo donde experimentas sin tocar el proyecto principal. La rama principal se llama `main`. El flujo profesional:

```
main (estable)  ────  rama nueva (experimento)  ────  revisión  ────  se une a main
```

**Analogía**: la rama es como **probar una receta en una cocina aparte** antes de servirla al restaurante. Por ahora solo entiende el concepto: cuando integremos "Soluciona" al portafolio (o cuando aprendas git de verdad), este concepto te salvará la vida una y otra vez.

## 5. Autoevaluación final (rúbrica — intenta el nivel 3 sin mirar)

| Criterio | Nivel 3 (Competente) |
|----------|----------------------|
| Crear repositorio | Lo creo desde la web en <5 minutos |
| Subir y editar | Subo y edito archivos con mensajes claros |
| Navegar cualquier repo | Encuentro cualquier documento siguiendo las reglas de orden |
| Explicar commits | Explico commit/historial/tachado con mis palabras |
| Seguridad | Aplico la lista de "nunca subir" y la 2FA |
| Ruta de lectura | Leo en orden: README → visión general → módulos |

Si logras marcar la columna entera: **aprobaste**. Si algo falta, repasa ese módulo específico (días 2-3) — el método de la rúbrica funciona en todas las guías.

1. Crea tu repositorio y súbele tu CV + 1 proyecto de práctica.
2. Edita tu README con: tu declaración de identidad (curso 0602 de la guía de soporte).

4. Escribe en tu README: "Estoy aprendiendo: [3 cosas]" — eso es marketing profesional real.
