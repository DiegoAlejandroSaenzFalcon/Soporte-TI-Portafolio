# Visión general — Guía de GitHub para principiantes

> **Esto es**: el manual de lectura de tu biblioteca digital.
> **Nivel**: cero absoluto → capaz de crear tu propio repositorio.

## ¿Por qué aprender GitHub?

| Escenario | Sin GitHub | Con GitHub |
|-----------|------------|------------|
| Quieres leer tu guía | Buscas archivos en carpetas locales | Navegas colección (Code) o la descargas en ZIP |
| Quieres ver el progreso | Sin historia | Los commits cuentan la historia completa |
| Quieres mostrarlo a un reclutador | "Tengo apuntes en mi PC" | "Mi portafolio está publicado y versionado" |
| Quieres colaborar | Enviar archivos por correo | Simplemente se comparte el repositorio |

## Mapa de los 6 módulos

```
M1 Conceptos (repositorio, público/privado)
   ↓
M2 Navegación (Code, migas de pan, documentos)
   ↓
M3 Commits (historial y texto tachado)
   ↓
M4 Descarga (ZIP) y trabajo local
   ↓
M5 Cuenta y seguridad de buenas prácticas
   ↓
M6 Proyecto: tu primer repositorio
```

## Herramientas necesarias

- Navegador web (cualquiera) — todo se hace desde la web.
- Cuenta gratuita en GitHub (opcional para leer; obligatoria para el módulo 6).
- Esta propia guía como laboratorio práctico.

## Reglas transversales

1. **La pestaña Code es tu zona de estudio** (Regla de oro).
2. **Github ordena alfabéticamente**: el "desorden" tiene lógica (la explican en el módulo 2).
3. **Navegar no rompe nada**: leer es seguro; editar se aprende, no se improvisa.
4. **Método científico**: si algo "no se ve", observa (la ruta de arriba), formula una hipótesis (¿estoy en el nivel correcto?), prueba (haz clic en la miga de pan) y concluye.

## Documentos y archivos con los que practicarás

- Documentos Markdown (`*.md`): se abren renderizados.
- Diagramas (`*.svg`): se abren como imágenes.
- Carpetas: se abren navegando dentro.
