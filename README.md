# Soporte TI — Guía Completa de Aprendizaje

### Diego Alejandro Saenz Falcon · Soporte TI · Redes · Ciberseguridad · Automatización

> Esta es una **guía de estudio completa y gratuita** basada en el currículo oficial del **Google IT Support Professional Certificate** (Coursera), estructurada por **módulos y submódulos**, con teoría, diagramas visuales, prácticas, comandos, *checklists* de dominio y enlaces a **plataformas gratuitas** para practicar (Cisco NetAcad, Packet Tracer, TryHackMe, Wireshark, Linux Journey y más).

> **Nota honesta:** los certificados oficiales de Coursera requieren pago para el documento final, pero **aprender aquí es gratis**: todo el contenido académico del curso está condensado y ampliado en esta guía para dominar el tema de verdad.

---

## Cómo usar esta guía (metodología)

1. **Lee** la *visión general* del curso y el módulo correspondiente.
2. **Estudia** la teoría y revisa los diagramas (los verás renderizados en GitHub).
3. **Practica** en las plataformas gratuitas listadas al final de cada módulo (clave: se aprende haciendo).
4. **Completa** el checklist de dominio del módulo antes de avanzar.
5. **Repite** en orden: cada curso construye sobre el anterior.
